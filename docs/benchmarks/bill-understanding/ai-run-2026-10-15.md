# Funded AI baseline — October 15, 2026

Three authorized requests used the production OpenAI adapter, prompt, schema,
source-packet builder, and output validator with `gpt-6-luna`, reasoning `none`,
and a 4,000-output-token cap per request. There were no automatic retries.

only database retrieval was replaced. No live bill records were modified.

## Offline citation triage

Across 99 generated quote references:

- 5 occur literally within their assigned source passage.
- 87 additional quotes occur after whitespace-only normalization.
- 7 still do not occur in the assigned passage after that normalization.

These diagnostic counts check substring presence, not uniqueness, legal meaning,
or whether the passage supports the claim. They do not override validation.
The seven remaining mismatches require distinguishing incorrect source references,
chunk-boundary problems, and text alterations such as hyphen changes. Simply
relaxing whitespace matching would not make these outputs valid.

The exact validator stopped at the first mismatch in each response. The complete
raw structured outputs, source snapshots, source/request hashes, token usage,
and validation messages are retained in
[the funded artifact](ai-baseline-2026-10-15-funded.json). This artifact contains
no API key. The earlier failed billing attempt is preserved separately.
